# Raintrace

Agent-selected direction for a public-data research workbench, informed by Jhona's approved TALLER and ANDÉN interfaces. This exact design has not yet received user approval.

Paper #f5f3ed, ink #172d37, muted ink #52646b, ocean #155b74, pale ocean #e7f0f2. Orange is reserved for incomplete data; red for integrity failures. Data is the focal point, with an editorial report and compact query controls. Segoe UI for controls and Georgia for the report title. No decorative badges, photography, cursor effects or dashboard filler.

This static, dependency-free implementation deliberately uses browser-native modules and CSS, so judges can run the same calculation without package downloads or keys. Motion is limited to short control feedback and disabled under reduced motion. All values and source provenance remain visible without animation.
